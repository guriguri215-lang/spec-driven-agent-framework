# Contributing

This project is in a local bootstrap phase and is not yet open for external
contributions.

For approved local work:

1. Read `AGENTS.md` and the active execution plan.
2. Keep changes within the approved requirement scope.
3. Add or update tests with implementation changes.
4. Run the commands documented in `docs/release-contract.md`.
5. Review the staged diff and publication audit before committing.
6. Use English for every tracked artifact and commit message.

Do not add production dependencies, select a license, publish a branch, or
change security boundaries without explicit Owner approval.
