# Support

## Release-candidate boundary

SDAQF `1.0.0rc1` is a prerelease for framework evaluators and advanced Codex
users. It is not intended for production use.

The Owner-approved A7 visibility-change command was accepted with exit code
`0` and no output, but no independent post-A7 remote read has confirmed
current public availability. Bug reports and documentation questions are
handled through GitHub Issues on a best-effort basis only after public
availability is independently confirmed. Support has no service level
agreement and applies only to the latest release.

External pull requests are not accepted during the release-candidate period.
No prerelease backports are promised.

## Security reports

Do not disclose a suspected vulnerability in a public issue. GitHub private
vulnerability reporting has not been enabled. Enabling it remains a separately
Owner-gated repository-setting change even if public visibility is later
confirmed. Until that channel is independently confirmed as enabled, keep the
report private and request the current disclosure instructions from the Owner.

## Maintenance

The final `1.0.0` release requires a new candidate and separate approval. After
that final release, Critical security and data-loss fixes are maintained on a
best-effort basis for six months. This commitment does not create an SLA.
