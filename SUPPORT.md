# Support

## Release-candidate boundary

SDAQF `1.0.0rc1` is a prerelease for framework evaluators and advanced Codex
users. It is not intended for production use.

Bug reports and documentation questions may be submitted through GitHub Issues
after the repository becomes public. Support is best effort, has no service
level agreement, and applies only to the latest release.

External pull requests are not accepted during the release-candidate period.
No prerelease backports are promised.

## Security reports

Do not disclose a suspected vulnerability in a public issue. GitHub private
vulnerability reporting is the intended channel only after it is enabled
through a separately approved repository-setting change when the repository is
public. Until that channel is confirmed, keep the report private and request
the current disclosure instructions from the Owner.

## Maintenance

The final `1.0.0` release requires a new candidate and separate approval. After
that final release, Critical security and data-loss fixes are maintained on a
best-effort basis for six months. This commitment does not create an SLA.
